# Trader Behavior vs Bitcoin Market Sentiment

## Objective
This project analyzes how Bitcoin market sentiment (Fear & Greed Index) influences trader performance using historical trade data from Hyperliquid.

## Datasets
1. Bitcoin Fear & Greed Index
2. Hyperliquid Historical Trader Data

## Methodology
1. Data Cleaning
2. Timestamp Alignment
3. Dataset Merging
4. Performance Analysis
5. Visualization

## Key Findings

• Traders generate higher profits during fear-driven markets  
• Long positions increase during greed phases  
• Leverage usage increases during bullish sentiment  
• Some profitable traders follow contrarian strategies
